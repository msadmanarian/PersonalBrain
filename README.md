## 🧠 What is PersonalBrain?

**PersonalBrain** is an industrial-grade, local-first **Second Brain & Cognitive Operating System** designed to augment human intellect through:
- **Bi-directional Knowledge Graphs**: Automatic `[[wikilink]]` extraction, PageRank centrality, and orphan thought discovery.
- **Spaced Repetition Memory Engine**: Inline `Q:: A` flashcard extraction and SuperMemo-2 (SM-2) scheduling.
- **Hierarchical Task & Project Dependency Engine**: Directed Acyclic Graph (DAG) task scheduling, Critical Path Method (CPM), and Kanban workflows.
- **Hybrid Search & Serendipity Discovery**: Blended BM25 lexical ranking and TF-IDF vector similarity to discover non-obvious conceptual bridges.
- **Interactive Cybernetic Visual Laboratory**: Zero-dependency web dashboard with force-directed physics graph.

## 🚀 Quickstart

```bash
# Clone repository
git clone git@github.com:msadmanarian/PersonalBrain.git
cd PersonalBrain

# Initialize and seed knowledge base
python run.py init

# View personal brain statistics
python run.py stats

# Search knowledge graph
python run.py search "Cognitive"

# Launch visual web lab
python run.py serve
```
